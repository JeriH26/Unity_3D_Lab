# Unity 3D Lab

This is a Unity 3D lab project for hands-on practice and research.

The project continuously builds different types of 3D scenes and explores multiple forms of 3D interaction, with a strong focus on AR/XR application scenarios and interaction experience.

## Project Goals

- Build a reusable Unity 3D environment for experiments
- Research multiple 3D interaction methods (gestures, input systems, object deformation, spatial feedback, and more)
- Explore design and implementation paths for human-computer interaction in AR/XR scenarios
- Rapidly validate technical solutions and interaction quality through small experiments

## Research Areas

- 3D scene construction and dynamic effects
- Shader/mesh deformation and visual presentation
- Unity Input System and interaction logic
- AR/XR prototype design and user experience validation

## Current Content

- Core Unity scene setup and project structure
- Cube to sphere deformation experiments (scripts and material effects)

## Roadmap

- Add more interactive scenes (grab, drag, scale, gaze interaction, etc.)
- Compare implementation approaches (CPU/GPU, Shader Graph/HLSL) in terms of performance and visual quality
- Expand AR/XR device adaptation and practical use cases
- Continuously improve documentation and experiment notes

## How to Use

1. Open this project folder in Unity
2. Open the experiment scene under Assets/Scenes (if available)
3. Run the scene and adjust Inspector parameters to observe different interactions and visual effects

## Notes

This repository is experiment-driven. Code and scenes will continue to evolve as research progresses.
